# Akari P0 Manual Acceptance Script

Last updated: 2026-06-12

按当前主路径手动验收 V2 MVP：聊天上传错题资料 → 选择是否入复盘 → 生成结构化诊断和每日复盘文档；规划与文件管理保持干净。

## 0. 验收前准备

### 启动应用

```bash
npm run dev:web
```

打开：`http://127.0.0.1:5173/`

如果端口被占用：

```text
[dev:web] Port 5173 is already in use. Stop the existing Akari dev server first.
```

不要接受 Vite 自动切到 `5174`。先停旧进程再重启。

### Settings 检查

- DeepSeek API key 已配置
- Base URL：`https://api.deepseek.com`
- Model：`deepseek-v4-flash`
- Workspace path：默认 `~/Desktop/Akari-WorkSpace` 或测试目录

### 准备测试文件

- 粉笔错题 PDF（必备）：例如 `~/Desktop/公务员行测-国考-行政执法类错题下载5题.pdf`
- 任意 JPG / JPEG（验证图片归档与预览）
- 任意 Markdown / 文本文件（验证普通文件对话）

## 1. 空状态文案与产品边界

### 操作

打开应用，左侧聊天面板无消息时观察空状态。

### 预期

- 标题：`Akari 随时都在`
- 下方一句产品边界说明，明确不替代粉笔错题本，而是提炼跨题诊断 / 记忆清单 / 训练建议
- 没有"OH-WorkSpace"漂浮标题
- 不出现"复盘候选"等内部分类术语

## 2. 拖入 PDF：默认普通文件对话

### 操作

1. 把粉笔错题 PDF 拖入聊天框（不要勾"入复盘"）。
2. 看到附件 chip：文件名、移除按钮、`入复盘` toggle。
3. 不输入任何文字，直接点 `发送`。

### 预期

- 文件名保留中文，不出现 `_______-______-...` 这种 latin1 乱码。
- 文件被上传到 Workspace 根目录（不是 `review/`）。
- 聊天里你看到的消息只显示：`附件：<文件名>`，不显示工作区路径或内部规则。
- Agent 普通文件对话回复，不调用复盘工具。
- 不生成 `reviews/*.md`。
- 右侧"复盘素材" tab 没有新增待确认条目。

## 3. 入复盘：粉笔 PDF 走结构化复盘

### 操作

1. 再次拖入同一份粉笔 PDF。
2. **勾选 `入复盘`**。
3. 输入一句简短上下文，例如 `资料分析增量这块我还是判断不准，帮我复盘`。
4. 点击发送。

### 预期

- 文件归档到 `review/<文件名>.pdf`，不在 Workspace 根目录。
- 聊天里可见消息附带：`已标记：入复盘`。
- Agent 调用 `record_pdf_review`，`confirmed_by_user: true`。
- Agent 回复**严格使用四段式 Markdown**：

  ```markdown
  ## 本次诊断
  - 主要问题：
  - 高频失误：
  - 不是知识点问题，而是：

  ## 记忆清单
  1.
  2.
  3.

  ## 回粉笔重做清单
  - 题号/题型：
  - 重做重点：
  - 不需要在 Akari 重做，回粉笔完成即可。

  ## 明日计划建议
  - 建议增加：
  - 建议减少：
  - 暂不调整：
  ```

- 段落顺序固定，缺失字段写"（暂无）"，不擅自加段落。
- `reviews/YYYY-MM-DD-daily-review.md` 被创建/更新，包含本次诊断。
- 内容不能编造 PDF 中没有的题号或解析。

## 4. JPG 上传：归档与预览，不假装识图

### 操作

1. 拖入一张 JPG / JPEG。
2. 观察 chip 旁的提示。
3. 不勾"入复盘"，直接发送。
4. 切到右侧 `工作台`，点击该 JPG。

### 预期

- chip 旁出现一行轻量提示：图片仅归档与预览；复盘建议附文字说明（不应是红色错误样式）。
- 文件在 Workspace 根目录。
- 右侧文件预览以图片形式显示，按比例缩放，不显示 base64 文本。
- 文件状态栏显示 `image/jpeg` 与文件大小，不显示行数。
- Agent 不假装读图。

## 5. 三 tab 信息架构：我的规划 / 复盘素材 / 工作台

### 我的规划

- 计划卡：目标、剩余天数、进度、本周任务数
- 计划卡下方有一个**可折叠**的 `计划版本` 区，默认收起
- 折叠区头部右侧是 `打开文档` 与 `刷新` 按钮（不展开也可点击）
- 展开后能看到当前计划与历史计划，支持归档 / 恢复 / 删除
- 不再有手动素材输入框
- 不再有学习复盘统计

### 复盘素材

- 顶部 `今日复盘` 卡，按钮 `打开当日复盘` 进入 `reviews/YYYY-MM-DD-daily-review.md`
- 下方一段文案说明：素材通过聊天附件勾"入复盘"归档到 `review/`，结果保存在 `reviews/`
- 如果有待确认素材才显示 `待确认素材` 区；没有时整块隐藏，**不显示空态文案**
- 不再显示计划版本
- 不再显示学习复盘
- 不再显示手动 candidate 提取入口

### 工作台

- 未选中文件：显示 Workspace 文件树
- 选中文件：显示预览（Markdown / 代码 / 图片 / PDF 文本）
- 没有 `OH-WorkSpace` 漂浮标题
- 没有右侧上传窗口（上传只在聊天框）

## 6. 我的规划：手动建立 + 编辑目标

### 操作

1. 如果当前已有 active 计划，先在 `我的规划 → 计划版本` 折叠区把当前计划归档，制造无 active plan 状态。
2. 在 `手动建立规划` 卡填入目标信息并创建。
3. 进入计划后点击 `编辑`，修改标题与描述并保存。

### 预期

- 无 active plan 时显示手动建立卡，不只是空状态。
- 创建后立即进入正常计划视图。
- 编辑后立即生效，刷新仍保留。

## 7. 我的规划：日视图 / 周视图与任务

### 操作

1. 切到日视图，点击非今日日期 chip。
2. 在某时间段 `+` 添加任务。
3. 切到周视图查看新任务。
4. 双击任务编辑标题 / 类型 / 分钟。
5. 把任务拖到另一天另一时间段。
6. 点击 checkbox 弹出反馈浮层，填用时 / 感受 / 状态 / 一句话感想，记录完成。
7. 测试浮层关闭：再次点击 checkbox / 点外部 / Esc 都只关闭浮层，不误完成。

### 预期

- 新任务落到选中日期，不是系统今天。
- 拖动跨天 / 跨时段生效。
- 完成后任务显示 `用时/预计 分`。
- 周视图 checkbox 直接完成，不弹反馈浮层。

## 8. 计划版本：归档 / 恢复 / 删除

### 操作

1. 让 Agent 生成一版新计划，制造历史版本。
2. 展开 `我的规划 → 计划版本` 折叠区。
3. 选历史计划点 `恢复`。
4. 选当前计划点 `归档`，确认弹窗。
5. 选历史计划点 `删除`，确认弹窗。

### 预期

- 历史可恢复为当前。
- 当前可归档；归档后 active 可为空。
- 历史可删除；active 不可直接删除。
- `plans/current-plan.md` 跟随当前计划同步。
- `plans/history/*.md` 跟随归档 / 删除变化。
- 不会动 `.akari/` 数据或 Workspace 中无关文件。

## 9. 当日复盘文档可回看

### 操作

1. 完成第 3 步入复盘后，进入 `复盘素材` tab。
2. 点 `打开当日复盘`。

### 预期

- 自动跳到 `工作台` tab 并打开 `reviews/YYYY-MM-DD-daily-review.md`。
- 文档包含本次入复盘生成的诊断段落。
- 同一天多次入复盘会累加更新，不覆盖。

## 10. 会话隔离

### 操作

1. 新建会话 A，做一次入复盘对话。
2. 新建会话 B，发送几条普通消息。
3. 切回会话 A。

### 预期

- 会话 A 的历史完整保留。
- B 的消息不污染 A。
- 左侧会话名是短标题，hover 可看完整 preview。

## 11. 端口占用与启动安全

### 操作

旧 dev server 仍在 5173 时再次运行 `npm run dev:web`。

### 预期

- 报错并提示先停旧进程。
- 不偷偷切到 5174。

## 通过标准

- 主路径四步全过：上传 → 选择是否入复盘 → 入复盘走四段式诊断 → 生成当日复盘文档。
- 三 tab 信息架构与本文一致，没有冗余卡片。
- 中文文件名保持原样；可见聊天消息不暴露内部规则文本。
- JPG 仅归档与预览，不被包装成识图能力。
- 计划与会话数据刷新后不丢；归档/删除不动 `.akari/` 或无关 Workspace 文件。
- Agent 输出基于真实文件文本，不编造原题或解析。
