# Superpowers Archive

本目录只保存 brainstorm、spec、plan 和 source material 的过程归档，不是 Akari 当前事实来源。

## 使用规则

- 当前权威文档入口是 `../README.md`。
- 本目录中的文档可能描述旧产品设想、旧技术栈或未实现方案。
- 如果某份 spec/plan 被采纳，必须先合并到 `docs/` 根目录的权威文档，再更新 `README.md` / `CLAUDE.md` 引用。
- 不要直接从本目录复制旧架构结论到实现中；先和当前代码、`docs/handoff.md`、`docs/roadmap.md` 对齐。

## 子目录

| 目录 | 内容 |
|---|---|
| `plans/` | 历史执行计划、演示脚本、阶段性方案 |
| `specs/` | brainstorm/spec/source material |
